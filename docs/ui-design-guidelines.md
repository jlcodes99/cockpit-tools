# 界面设计规范

## 设置弹框

- 历史存储等次要的多字段管理操作使用独立弹框。主页面只保留入口，打开时保持原内容的位置。
- 按任务组织正文。开关和它控制的字段放在同一组，统一标签、控件高度、列宽和间距。顶部可展示记录数、占用空间等有用状态。主操作和取消固定在底部，删除等危险操作在独立区域先预览再确认。
- 使用项目现有组件、设计变量和交互状态。长名称优先省略，窄窗口按需要改为单列。评审正常宽度、长名称和长译文，并验证 600px 高度下正文可滚动，关闭、取消和保存始终可达。点击遮罩不能关闭弹框。

## 账号与订阅套餐

- 展示具体账号的表格、卡片、复选列表、下拉选项及收起后的已选值，都同时显示账号名称和订阅套餐标识。
- 同平台复用账号总览的套餐展示逻辑和样式，保持原始套餐名称、配色、描边、形状及用户所选样式一致。套餐未知时使用平台的未知态。「全部账号」等集合选项无需套餐标识。
- 长账号名先省略，确保套餐标识可读。新增或修改账号选择入口时，核对该平台其他入口里的同一账号是否展示一致。
