# MiniMax Code 平台手动测试清单

> 开发环境：`npm run tauri:dev`（Windows 下脚本已自动处理 cargo 路径与 vcvars 环境）。
> 建议先跑一遍「A. 通用回归」，确认没有破坏既有平台，再跑 MiniMax Code 专属项。

## A. 通用回归（不能破坏其他平台）

- [ ] 侧边栏布局与升级前一致，codebuddy-suite 仍是 3 个成员（Codex / Claude / WorkBuddy），MiniMax Code 作为独立入口。
- [ ] WorkBuddy 账号页：登录、切换、配额、自动签到、签到弹窗状态均正常（重点：签到弹窗读写的是 WorkBuddy 自己的配置）。
- [ ] Codex 账号页：登录、切换、配额、多实例、本地网关状态正常。
- [ ] 其他平台（Claude、Cursor、Trae、Kiro 等）账号增删改查无回归。
- [ ] 托盘菜单里 MiniMax Code 的 id 与前端一致，点击能正确切换/打开。
- [ ] 设置页、快捷设置、悬浮卡片都能找到 MiniMax Code 入口。

## B. 账号来源

- [ ] **浏览器 OAuth**：添加账号 → 浏览器打开 `account.minimax.cn` 授权页 → 完成授权 → 账号自动落库，邮箱/昵称正确。
- [ ] **内置 WebView 授权**：能打开授权页，顶部步骤条推进正常，授权完成后账号落库。
- [ ] **粘贴 Token**：粘贴 access token 导入成功。
- [ ] **JSON 文件导入**：选择官方导出 JSON 导入成功。
- [ ] **从本机客户端导入**：`从本机 MiniMax Code 导入` 能读到 `~/.minimax/auth/<env>/<region>/mcode-public/auth.json`。
- [ ] **多账号 id 不塌缩**：连续导入两个不同 dataDir 的本机账号，列表中是两个账号（不是互相覆盖）。
- [ ] 切换 region（cn / en）导入的账号各自独立。

## C. 账号切换与登录态写入

- [ ] 切换账号后，官方客户端的 `auth.json` 记录键与 Cockpit 写入的一致（可用临时 `MINIMAX_DATA_DIR` 隔离验证）。
- [ ] 切换账号后 `auth-state.json` 的 `generation` 与 `auth.json` 中的 `generation` 一致。
- [ ] 切换后官方客户端能直接登录进对应账号（不弹登录窗）。
- [ ] 切换前若官方客户端正在运行，会被关闭后再写入（不出现写入被占用）。
- [ ] 注入失败时保留原文件、不覆盖（官方加密封装无法解密时）。

## D. 配额

- [ ] 账号卡片按资源包展示额度、进度、刷新/到期时间，UI 与 WorkBuddy 一致。
- [ ] 配额数据来自 `credit/details` 接口，过期/异常状态有对应展示。
- [ ] 刷新配额不会覆盖账号的其他字段。

## E. 每日签到

- [ ] 手动签到：显示「已签到 / 未签到」，签到后变为已签到，奖励天数正确。
- [ ] 重复签到不会把连续天数刷高（重复领取被识别为 already claimed）。
- [ ] 签到活动未开启/不适用时显示「不可用」，不报错。
- [ ] 一键签到：批量账号逐个签到，失败有重试入口。
- [ ] **自动签到**：开启后到点自动完成；连续天数跨天递增；Token 过期时先刷新再签到。
- [ ] 自动签到配置弹窗读写的是 MiniMax Code 自己的配置（不影响 WorkBuddy）。

## F. 应用多开（实例）

- [ ] 新建实例生成独立数据目录（`managed_instances/minimax_code/...`）。
- [ ] 实例可启动 / 停止 / 重启 / 全部启动 / 全部停止。
- [ ] 实例绑定账号后，启动的是该账号的登录态（客户端不弹登录窗）。
- [ ] 多实例并行运行互不干扰（各自独立 dataDir）。
- [ ] 导入已有目录、复制登录状态、空白实例三种初始化方式都可用。
- [ ] 实例列表的配额、状态、上次启动时间显示正确。

## G. 设置与集成

- [ ] 设置页可配置 MiniMax Code 应用路径，支持「恢复默认」。
- [ ] 自动刷新间隔可配置。
- [ ] 数据迁移/导出包含 MiniMax Code 账号。
- [ ] 全局标签操作覆盖 MiniMax Code 账号。
- [ ] 18 个语言包都有 MiniMax Code 文案（无缺失 key、无硬编码中文）。

## H. 风险项

- [ ] `~/.minimax/auth/.../auth.json` 在 Cockpit 写入前后有备份（`auth.json.cockpit.bak`），且不会无限累积 `.bak`。
- [ ] 卸载/清理实例目录时不会误删账号数据。
- [ ] 代理引擎（cliproxy）相关功能不受影响。
