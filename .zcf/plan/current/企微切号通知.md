# 企微切号通知

创建时间：2026-05-11 20:38:38 CST

## 上下文

- 任务：增加企微机器人通知能力，切换到其他账号时发送消息通知。
- 用户确认：按建议执行；webhook 调整为内置；确认内置并执行。
- 方案：Rust 后端集中通知，通知失败只记录日志，不阻断切号。
- 风险确认：用户已确认将企微 webhook 内置到源码。

## 执行计划

1. 新增 `src-tauri/src/modules/wecom_switch_notify.rs`，封装企微 markdown 通知、脱敏、异步发送。
2. 在 `src-tauri/src/modules/mod.rs` 注册模块。
3. 在 `src-tauri/src/modules/config.rs` 新增企微切号通知开关和内置 webhook 默认值。
4. 在 `src-tauri/src/commands/system.rs` 暴露通用配置字段并保证保存设置不丢字段。
5. 在 Antigravity、Codex、GitHub Copilot、Windsurf、Kiro、Cursor、Gemini、CodeBuddy、CodeBuddy CN、Qoder、Trae、WorkBuddy、Zed 切号成功路径发送通知。
6. 在设置页保留启用/关闭开关，不提供 webhook 输入框。
7. 运行 `npm run typecheck`、`cargo check -p cockpit-tools` 和通知模块相关测试。

## 验收标准

- 所有主要账号切换成功路径触发企微通知。
- 账号展示值脱敏。
- 企微发送失败不影响切号。
- 不真实调用企微 webhook 进行测试。
